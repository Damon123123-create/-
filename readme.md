- 测试日期：2026.10.5
- 开发板：RoboMaster 开发板 C 型
- 遥控器及接收机：DT7、DR16
- 下载方式：正点原子无线调试器，使用 OpenOCD 下载
- 结果：四项基本功能现场验证通过

### 测试结果

| 功能 | 测试方法 | 实际结果 |
|---|---|---|
| 蜂鸣器 | 烧录后复位运行，检查启动提示音 | 提示音正常，约 200 ms 后停止 |
| LED | 观察灯效，并在操作遥控器、打印数据时持续观察 | 红、绿、蓝依次点亮，约每 300 ms 切换，联合运行时持续流水 |
| IMU 串口打印 | 静止、翻转及转动 C 板，观察输出 | 加速度和角速度数据持续输出，随板子姿态和运动变化 |
| DT7 通信 | 操作两个摇杆、两个三档拨杆，关闭后重新开启遥控器 | 通道及拨杆数据响应正常，断联状态与恢复接收正常 |

### 串口连接与参数

使用 USB 转串口模块，C 板 USART1 的 TXD 接模块 RXD，GND 共地。C 板独立供电，模块 VCC 不接。按开发板手册确认接口及线序。

- 波特率：115200
- 数据位：8
- 校验：无
- 停止位：1
- 流控：无
- 接收模式：文本

### 输出说明

- `ACC[mm/s2]`：X、Y、Z 三轴加速度，除以 1000 得到 m/s²。
- `GYR[mdeg/s]`：X、Y、Z 三轴角速度，除以 1000 得到 °/s。
- `RC=ON/OFF`：是否近期收到有效遥控器数据。
- `CH`：四个摇杆通道，回中时接近 0，端点约为 ±660。
- `SW`：两个拨杆，1、3、2 分别表示上、中、下档。

### 实测数据示例

静止、近似水平放置时：

```text
ACC[mm/s2]=-68,-132,9780 GYR[mdeg/s]=-183,-305,122 RC=OFF CH=0,0,0,0 SW=0,0
```

操作遥控器时：

```text
ACC[mm/s2]=-879,8254,-4896 GYR[mdeg/s]=-122,-244,61 RC=ON CH=660,-5,660,-660 SW=3,3
```
